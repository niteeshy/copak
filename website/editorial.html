[TECHNICAL INQUIRIES // FAQ]
How does Copak differ from native Claude Code or Cursor memory? [-]
Agent context windows fill quickly and drift during complex sessions. When opening a fresh session or debugging in a web LLM, you are forced to re-explain the architecture. Copak generates a sanitized, structured snapshot containing your immediate momentum and recent repo diff in one keystroke (⌘⇧H / ⌘↵).
Does Copak transmit code to any remote server or cloud account? [+]
No. Copak is 100% offline. It makes zero network calls, contains zero analytics or telemetry SDKs, and stores session state strictly on your local disk in ~/.copak/sessions/.
Can Copak be used with non-git project directories? [+]
Yes. Copak automatically detects directories outside Git, analyzing file trees, scanning TODOs, and ingesting rule files while gracefully omitting Git-specific diff sections.
How is Copak packaged and distributed? [+]
Copak is distributed as a universal macOS application (supporting Apple Silicon and Intel Macs). Simply download Copak.zip from GitHub Releases and drag Copak.app into your /Applications directory.
