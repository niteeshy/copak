The Architecture

Deterministic Momentum vs. Black-Box Memory

Vector databases and "autonomous memory" hallucinate stale code and lose nuance. Copak pairs developer-maintained intent with automated inspection.

Autonomous Memory Tools

Fuzzy & Unpredictable

  • ❌ Retrieves outdated code snippets from 2 weeks ago
  • ❌ Leaks API keys and .env variables into prompt context
  • ❌ Unbounded token dumps dilute model attention and reasoning
  • ❌ Invisible background daemons running cloud syncs & telemetry
Copak Handoffs

Explicit & Deterministic

  • ✓ Developer maintains goals, decisions, and active task queues
  • ✓ Multi-layer sanitization strips secrets before touching clipboard
  • ✓ Enforced token ceilings (1k, 3.5k, 10k) with trim disclosures
  • ✓ 100% offline, native Swift, local atomic JSON storage

Questions & Answers

Frequently Asked Questions

How is Copak different from Cursor or Claude Code memory? ▼
Agents operate with context windows that fill up quickly and drift over long sessions. When starting a new session or debugging in a separate web LLM, you have to re-explain the architecture. Copak generates a sanitized, compact snapshot of your immediate momentum and repo diff so the new agent is up to speed in seconds.
Does Copak upload my code or send data anywhere? ▼
No. Copak is 100% offline. It has zero network calls, zero analytics, and zero cloud accounts. Everything is parsed locally on your Mac and copied directly to your clipboard.
Does it work on projects that are not Git repositories? ▼
Yes! Copak gracefully detects non-git folders, extracts directory file trees, analyzes TODOs, and ingests instruction files while omitting Git-specific diff sections.
How do I install it on macOS? ▼
Simply download Copak.zip from GitHub Releases, extract it, and move Copak.app into your /Applications folder. If Gatekeeper prompts on first launch, right-click and choose "Open" or run xattr -cr /Applications/Copak.app.
